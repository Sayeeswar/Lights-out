# Project Guide

This repository contains an SBI personal-loan voice assistant and a separate
Yahoo Finance equity-research project.

## SBI Loan Voice Agent

To run the voice agent, first navigate to the [`Voice_agent_SBI_LOAN/`](./Voice_agent_SBI_LOAN/)
folder. Then open its [`Readme.md`](./Voice_agent_SBI_LOAN/Readme.md) and follow
the setup and run instructions there. That guide covers dependencies, the local
OpenAI API key, starting the web server, and opening the browser interface.

## Other folders

- [`yahoo-finance-ai/`](./yahoo-finance-ai/) — A separate equity-research AI
  application. Its README explains the API, frontend, and deployment.
- [`Testing/`](./Testing/) — Small Yahoo Finance experiments; `Yahoo.py`
  currently fetches and prints quarterly balance-sheet data for INFY.NS.
- `env/` — A local Python virtual environment. It contains installed packages
  and is machine-specific; it should not be committed to Git.
- `__pycache__/` — Python-generated bytecode cache files. These are disposable
  and can be regenerated automatically.

The voice assistant and Yahoo Finance application are separate projects with
their own dependencies and run instructions.
